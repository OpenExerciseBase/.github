# OpenExerciseBase

**An open, evolving infrastructure for structured exercise knowledge.**

OpenExerciseBase supports the contribution, revision, professional validation, and reuse of machine-readable exercise knowledge across research, rehabilitation, digital health, and other applications.

[Website](https://openexercisedatabase.at) · [Documentation](https://openexercisedatabase.at/documentation) · [Explore exercises](https://openexercisedatabase.at/explore) · [Dataset statistics](https://openexercisedatabase.at/insights)

## Repositories

| Repository | Description |
|---|---|
| [OpenExerciseBase-Database](https://github.com/OpenExerciseBase/OpenExerciseBase-Database) | The exercise data: one JSON file per exercise, with images, version history, and review status. |
| [OpenExerciseBase-Web-Platform](https://github.com/OpenExerciseBase/OpenExerciseBase-Web-Platform) | The website for browsing, contributing, and reviewing exercises. |

## Using the data

The `main` branch of the database holds exercises that have undergone professional review. The `community` branch holds contributed exercises that are unreviewed or were rejected. The data is available by cloning the repository, through the website, and through the read API (`/api/exercises`). See the [documentation](https://openexercisedatabase.at/documentation) for details.

The data is licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).

## Contributing

Anyone can propose a new exercise or an improvement through the website. Contribution and professional review are separate processes. See the [contribution guidelines](https://openexercisedatabase.at/contribution-guidelines).
